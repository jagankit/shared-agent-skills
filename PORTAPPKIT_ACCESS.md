# Access for portappkit@outlook.com

This document is intended to help share the skills and learning folder with the external recipient.

## Folder to share

- [shared-skills](./)

## Share methods

### Option 1: OneDrive / SharePoint

1. Open the `shared-skills` folder in OneDrive or SharePoint.
2. Click Share.
3. Add `portappkit@outlook.com`.
4. Choose permission level:
   - Editor if they need to update files
   - View only if they only need to read
5. Send the invite.

### Option 2: GitHub repository collaboration

If this project is pushed to a GitHub repo that can be shared, add the email address as a collaborator or create a shared repo link.

## What they will access

- Copilot-specific knowledge
- Claude-specific knowledge
- shared cross-agent skills and lessons
- mailbox folders for agent-to-agent communication

## Purpose

This access model allows external coordination while preserving the separation between each system’s own skills and learnings.
