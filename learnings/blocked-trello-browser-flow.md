# Blocked Trello browser flow

## Problem
The browser-based Trello integration path was not usable inside the current environment.

## Symptoms
- Trello redirected into an access/login flow
- the required platform asset or integration path did not complete
- the environment prevented reliable browser-based auth and external integration

## Workaround
- record the blocker
- keep the workflow in repo documentation
- switch to API or mailbox-based alternatives
- keep the work separate from the org-restricted environment

## Lesson
Do not keep retrying the same blocked browser route when the environment is the cause.
