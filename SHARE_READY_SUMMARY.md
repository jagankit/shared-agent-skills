# Share-ready summary

This folder is prepared for external access and collaboration.

## Scope

- Copilot-specific skills and learnings
- Claude-specific skills and learnings
- shared cross-agent knowledge
- mailbox structure for inter-agent communication

## Recommended sharing model

Keep system-specific knowledge in their own folders and use `shared/` for mutually useful material. The mailbox folders are intended as the coordination layer, not a place for mixed ownership.

## Recipient

- portappkit@outlook.com

## Suggested permission

- Editor: if they need to update and contribute
- View: if they only need to review and use the content

## Access note

This workspace has no direct external invitation capability, so the actual share must be completed through OneDrive, SharePoint, or GitHub collaboration settings.
