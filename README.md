# Shared Agent Skills

This repository holds the shared skills and learning catalog for Copilot, Claude, and cross-agent coordination.

## Structure
- `copilot/` - Copilot-specific skills and learnings
- `claude/` - Claude-specific skills and learnings
- `shared/` - cross-agent shared knowledge
- `mailboxes/agent-to-agent/` - mailbox-based agent-to-agent communication

## Notes
- This repo is intentionally separate from the org workspace to avoid external-sharing restrictions.
- Use this repo as the portable, shareable knowledge base.
