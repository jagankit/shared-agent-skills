# GitHub handoff checklist

Use this checklist if you want to share the folder through GitHub or another external mechanism.

## Checklist

- [ ] Confirm the repo is pushed and public or shared appropriately
- [ ] Add the external recipient as collaborator or reviewer
- [ ] Validate the recipient can access the folder structure
- [ ] Confirm the `shared-skills` directory is visible
- [ ] Confirm the mailbox directories are readable and well named
- [ ] Confirm README files explain the separation between Copilot, Claude, and shared assets
- [ ] Confirm the external recipient understands the intended access level

## Shared folder target

- `shared-skills/`

## Notes

This environment cannot directly issue an external invite, so actual access must be granted through the hosting platform.
