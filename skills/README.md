# Skills catalog

This folder contains the initial reusable skills for the shared agent environment.

## Included skills

- `copilot-agent-patterns` - reusable Copilot workflow patterns
- `claude-agent-patterns` - reusable Claude workflow patterns
- `shared-coordination` - shared agent coordination and message-handling guidance
- `knowledge-transfer` - transfer of learnings across agent systems

## Purpose

These entries are intentionally lightweight and reusable so that both agents can reference a shared vocabulary and workflow base.
